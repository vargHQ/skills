# AGENTS.md

vargHQ/skills is a library of Agent Skills for AI video, image, voice and music. Each top-level folder with a `SKILL.md` is one skill.

## Use a skill

1. Find the person's task in the index below (or in [catalog.json](catalog.json)). If nothing fits, search the keyless varg how to MCP (`https://api.varg.ai/v2/skills/mcp`: `search_how_to`, then `get_how_to`) or read [`how-to-make-ai-video/SKILL.md`](how-to-make-ai-video/SKILL.md).
2. Read `<skill>/SKILL.md` before anything else. It lists the inputs to ask for, the choices to put to the person, the steps, the prompts and the checks. Load its `references/` only when the SKILL.md points there.
3. Ask the two to four choices the skill names, in the person's language, before spending anything.
4. Skills that generate spend varg credits (1 credit = $0.01, provider price). Approve stills before video, call `estimate_cost` before a batch, a long video or a render, and wait for the person's yes. Never clear a cache.
5. Check the output the way the skill says (frames, loudness, text in the safe zone, faces and product unchanged) before handing over files.

Generate with the varg MCP (`https://mcp.varg.ai/mcp`, OAuth) or `VARG_API_KEY` against `https://api.varg.ai/v2`. Current model ids, inputs and limits: https://varg.ai/models/llms.txt.

## Work on this repo

- Skill folders are lowercase-hyphen and match the `name` in their `SKILL.md` frontmatter. Keep `SKILL.md` under 500 lines; put detail in `references/`.
- `README.md`, `how-to/**/README.md`, every `<skill>/README.md`, `llms.txt`, `catalog.json`, `context7.json` and the index block above are generated. Edit `SKILL.md`, `.github/readme/skills.json` (title, tagline, category, example requests, preview) or `.github/readme/use-cases.json` (one guide per task), then run `bun .github/readme/build.ts`. CI runs it with `--check`.
- A new skill also goes into `.claude-plugin/plugin.json` → `skills`, and into at least one use case. The build fails until it is.
- Never commit media (mp4, mov, webm, gif, mp3, wav, large png/jpg). Upload previews to s3.varg.ai and link them.
- English only. No real people's names or faces in examples unless they are the skill's credited author. Credit third-party work to its author.
- Never commit `.env`, keys or tokens.
